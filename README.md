One line roasting a smart fridge for make.fun's "Fridge Roast: One Line, Biggest Laugh" bounty:

> My fridge flagged my midnight snack as a security threat and locked the crisper. It was a pickle. I live here.

`main.py` (standard library only) writes the line to `/output/entry.txt`
with no trailing newline, mode 0644.

## Run it

```sh
python3 main.py
```
